# 📚 图书管理系统

一个基于 C# WPF 开发的桌面图书管理系统，提供图书的录入、借阅、归还、分类筛选等核心功能，采用现代化的 UI 界面设计。

## ✨ 功能特性

### 用户管理
- **用户注册**：支持新用户注册账号
- **用户登录**：账号密码登录验证
- **密码重置**：支持忘记密码时重置密码
- **退出登录**：安全退出当前账户

### 图书管理
- **图书录入**：录入新图书，填写书名、作者、ISBN、分类等信息
- **图书展示**：以卡片形式展示图书信息，直观清晰
- **分类筛选**：支持按分类（文学小说、科学技术、历史传记、哲学思想、艺术设计、经济管理、教育学习）筛选图书
- **图书统计**：实时显示当前分类下的图书总数

### 借阅管理
- **图书借阅**：记录借阅人姓名和借阅日期
- **图书归还**：归还已借出的图书，自动清除借阅记录
- **状态标识**：借出的图书以灰色卡片标识，在馆图书以蓝色边框标识
- **借阅信息**：实时显示借阅人和借阅状态

## 🚀 快速开始

### 环境要求

- **操作系统**：Windows 10 / Windows 11
- **开发工具**：Visual Studio 2022 或更高版本
- **.NET SDK**：根据项目配置的 .NET 版本

### 运行步骤

1. **克隆仓库**
   ```bash
   git clone https://github.com/yourk-xiaoluo/C-_project.git
   ```

2. **打开项目**

   使用 Visual Studio 打开 `WpfApp3.slnx` 解决方案文件

3. **还原依赖并运行**

   在 Visual Studio 中点击 `启动` 或按 `F5` 运行项目

## 📖 使用说明

1. 启动应用后，首先进入**登录界面**
2. 新用户需要先**注册账号**
3. 登录成功后进入**图书管理主界面**
4. 在主界面可以：
   - 浏览所有图书卡片
   - 通过下拉框**筛选**不同分类的图书
   - 点击**「录入」**按钮添加新图书
   - 点击图书卡片上的**「借阅」**按钮借阅图书（需输入借阅人姓名）
   - 点击已借出图书的**「归还」**按钮归还图书
   - 点击**「退出登录」**返回登录界面
